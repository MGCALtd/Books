# Migration Without Guesswork

Original companion examples and blank templates for Alexander Marinov's MGCA book.

All files for this book live in this folder. The book manuscript and internal review notes are not included.

## Run

Download this folder, use Python 3.12 or later with sqlite3, then run:

```sh
python verify_examples.py
```

Use only the supplied fictional inputs. See README.txt, LICENSE.txt, ERRATA.txt and VERSION_HISTORY.txt. SHA256SUMS.json covers the companion content files. Checksums detect accidental changes; this repository is not an independent authenticated checksum service.
