# Migration Without Guesswork

Companion examples and blank templates by Alexander Marinov (MGCA).

All files for this book live in this folder. Download this folder, use Python 3.12 or later with sqlite3, and run `python verify_examples.py`.

See README.txt, LICENSE.txt, ERRATA.txt and VERSION_HISTORY.txt. SHA256SUMS.json covers the companion content files. Checksums detect accidents; this repository is not an independent authenticated checksum service.

Companion revision 0.5.0. Clean-machine CI and Kindle/device proofing remain pending. Manuscript and internal review files are not included.
